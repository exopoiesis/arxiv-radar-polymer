# New Laplace convolution integrals involving exponential, error, and parabolic cylinder functions with applications in heat transfer and linear viscoelasticity

**Authors:** González Santander, Juan Luis

We compute several new Laplace convolution integrals involving exponential functions, error functions, and parabolic cylinder functions. We extend our results using formulas for repeated integration and differentiation. We apply these convolution integrals to heat transfer and linear viscoelastic problems. As a by-product, we obtain new integral representations for the error function and the complementary error function.
