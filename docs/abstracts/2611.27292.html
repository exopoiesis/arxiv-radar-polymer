Two-phase visco-elastic FENE-P model: Thermodynamically consistent modeling, sharp interface limit analysis and unconditionally energy stable numerical scheme

Yuzhe Qin, Dongdong He

arXiv:2611.27292·math.NA·Published 2026-11-20

Although mathematical modeling and numerical simulations for two-phase Newtonian flows have been extensively studied for many years, relatively little work has focused on developing thermodynamically consistent models for two-phase Non-Newtonian viscoelastic flows, and to the author's best konowledge, no structure-preserving numerical methods have been reported for such models. In this paper, we focus on modeling the two-phase non-Newtonnian visco-elastic FENE-P model based on the energetic variational approach (EnVarA). In the model, a phase-field function is introduced to describe the diffuse interface which satisfies the Cahn-Hilliard (CH) equation. And all the physical variables can be connected smoothly. We conduct a matched asymptotic analysis for the sharp interface limit, which shows the diffuse interface model will converge to the sharp interface model when the interface thickness trends to zero. We then reformulate the model in an equivalent form that facilitates the construction of the numerical scheme. A weakly decoupled scheme is proposed for the resulting FENE-P-CH system, and its unconditional energy stability is proved theoretically. Finally, a series of numerical experiments is conducted to validate the model and assess the performance of the proposed scheme.
