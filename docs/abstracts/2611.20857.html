Will it bend? Modelling hydrogel box hinges with a gel Lattice Spring Method

Ellen M Jolley, Katie A Phillips, Guy Harrop, Gerard Cummins, Tom D Montenegro-Johnson

arXiv:2611.20857·physics.flu-dyn·Published 2026-11-16

Hydrogels are biocompatible smart materials comprised of a hydrophilic polymer network which can absorb a large volume of water (swelling). The changes in shape the gel undergoes as it swells or de-swells can be utilised in the design of actuators. This is of particular interest for many applications whereby hydrogel actuators would be combined into a complex origami-inspired structure which can fold and unfold according to application needs. In this paper, we therefore focus on one such actuator design, the bilayer hinge, which can induce bending (for potential use in a fold/unfold mechanism). We develop a model using the gel lattice spring method (gLSM) which can be used to simulate composite structures comprised of hydrogel and elastomer and compute the equilibrium bending angle of bilayer hinges for a range of geometries and material properties.
